# Crestline Supply Group

Premium corporate procurement and commercial supply platform serving businesses, institutions, schools and organisations across Zimbabwe.

## Development
- React + TypeScript + Vite
- `npm install`
- `npm run dev`
- `npm run build`

## Launch notes
Crestline Supply Group is a working brand pending legal name and domain availability checks. The website intentionally avoids claims of registration, PRAZ approval, established supplier relationships, stock, prices, delivery coverage, customers or certifications until verified.

The catalogue is illustrative and quotation-led. Contact channels and a real enquiry delivery backend must be configured before launch. The quotation form currently captures details in the browser and offers copy-to-clipboard; it does not transmit submissions to the company.
